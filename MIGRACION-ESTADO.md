# Estado actual

La aplicación Laravel incluye vistas, controladores, validaciones, middleware, modelos,
servicios, assets, seeders y pruebas. Se conecta a las tablas existentes de scoutbo.
El origen no fue modificado.

Consulta `README.md`, `docs/MIGRACION.md` y `docs/GUIA-DEL-CODIGO.md`.
La ejecución de migraciones en scoutbo requiere la confirmación explícita pendiente;
no necesitas reconstruir la base para iniciar el sitio.
